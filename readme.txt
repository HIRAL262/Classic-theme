== Description ==

Meridian is a clean, accessible, translation-ready classic WordPress theme built from scratch with plain CSS and no build step. It ships with a primary and footer navigation menu, a sidebar and three footer widget areas, custom logo support, threaded comments, and a full set of standard template files.

== Installation ==

1. Upload the `meridian` folder to `/wp-content/themes/`.
2. Activate the theme through the "Appearance > Themes" screen in wp-admin.
3. Assign menus under "Appearance > Menus" (Primary Menu / Footer Menu).
4. Add widgets under "Appearance > Widgets" (Sidebar / Footer 1-3).

== Frequently Asked Questions ==

= Does this theme support any plugins? =

Meridian follows core WordPress APIs (menus, widgets, custom logo, post thumbnails) so it is compatible with standard plugins that rely on those APIs.
